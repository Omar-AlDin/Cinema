# Cinema Cafe 🎬

A modern movie and TV discovery platform built with vanilla HTML, CSS, and JavaScript.

Cinema Cafe combines movie and TV discovery with a cinematic interface, detailed media pages, genre exploration, search, and a movie guessing game.

## 🌐 Live Demo

▶️ **[Launch Cinema Cafe App](https://omar-aldin.github.io/Cinema/)**

## ✨ Features

- 🎬 Movie and TV show discovery
- 🔎 Search for movies and TV shows
- 🎭 Genre exploration
- 📚 Detailed movie and TV show pages
- 📺 TV seasons and episode information
- 🎞️ Trailers and media sections
- ⭐ Ratings and movie information
- 💎 Curated "Hidden Gems" section
- 🎲 Interactive Movie Guessing Game
- 🎥 Movie Night feature concept
- 📱 Fully responsive design for desktop, tablet, and mobile
- 🔄 Infinite scrolling
- 💾 Session-based state and scroll restoration
- 🌐 Arabic and English movie search support
- ⚠️ Network error handling for key API interactions

## 🛠️ Built With

- HTML5
- CSS3

## 🎯 Project Goals

Cinema Cafe was built as a hands-on project to strengthen my frontend development skills and learn how to build a larger application from scratch.

The project focuses on:

- DOM manipulation
- Working with REST APIs
- Asynchronous JavaScript
- Dynamic rendering
- State persistence
- Infinite scrolling
- Responsive UI development
- Error handling
- UI/UX design
- Building reusable interface patterns

## 📱 Responsive Design

Cinema Cafe was designed specifically for three different layouts rather than simply scaling down the desktop interface:

- Desktop
- Tablet
- Mobile

Several pages use different compositions at each breakpoint, particularly the media details pages.

## 🎲 Movie Guessing Game

Cinema Cafe includes an interactive movie guessing game powered by the TMDB API.

Players are given movie imagery and attempt to identify the movie, with support for hints, scoring, skipping, and Arabic/English answers.

## 🎥 Movie Nights

Movie Nights is a planned feature that connects movie discovery with real-world movie events.

The current version presents the concept and user experience, while the functionality is planned for a future full-stack version.
